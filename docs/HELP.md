# ZoreView 使用帮助

ZoreView 是一个 Windows 原生的轻量看图软件，单进程、无联网、无遥测。
本文件随安装包/便携包一起分发。

## 系统要求

- Windows 10 1809 或更高版本 / Windows 11，x64。
- 建议启用 DirectX 11 显卡驱动；无独显时使用 WARP 软件渲染。
- HEIC/HEIF、AVIF 需要系统解码扩展（见“常见问题”）。
- 可选：资源管理器缩略图和右键菜单需要用户级注册（不需要管理员）。

## 安装与便携版

- **当前用户安装**：运行 `Install.cmd`（或 `zoreview.exe --install`），安装到
  `%LOCALAPPDATA%\Programs\ZoreView`，不需要管理员权限。
- **全机安装**：管理员命令行执行 `zoreview.exe --install --machine`，安装到
  `%ProgramFiles%\ZoreView`。
- **便携版**：解压后直接运行 `zoreview.exe`。包内的 `ZoreView.portable`
  会让设置、缓存、日志、壁纸都留在 exe 同目录。
- 卸载：运行 `Uninstall.cmd`，或在“设置 → 应用 → 已安装的应用”中卸载。
  卸载会清理程序、开始菜单快捷方式和注册表项，不删除你的图片。

安装前建议先双击 `Verify.cmd`：它会逐文件核对 `SHA256.txt`，文件被改动时拒绝安装。

## 打开图片

- 双击图片、拖放文件到窗口、`Ctrl+O`，或命令行 `zoreview.exe <文件>`。
- 拖放**文件夹**会打开其中第一张图片并建立缩略图条；拖入空文件夹会显示
  “此文件夹没有支持的图片”。拖入不支持的文件只提示，不会清空当前图片。
- 启动时没有图片会显示空态卡片：可以点“选择图片”“打开文件夹”或
  “查看全部格式”，也可以用 `Tab` / `Shift+Tab` 切换按钮、`Enter` 激活。
- 同一目录内用 `←` / `→` 切换上一张/下一张；到边界时的行为可选
  **本文件循环**（默认，只在当前文件夹里绕回第一张）、**下个文件夹**
  （跳过没有图片的子目录）或**询问**
  （询问浮层里可勾选“记住我的选择”，`Enter` 进入、`Esc` 留下、`Space` 切换）。
- 当前文件夹会被**自动监视**：外部新增/删除/重命名会在约 2 秒内更新缩略图条和
  标题序号，当前图片尽量保持不变；当前文件被删除时自动切到下一张，删空后显示
  空态；文件内容被其他程序修改时只提示“按 F5 重新加载”，不会自动覆盖你的缩放。
  窗口最小化或设置/确认浮层打开时暂停监视。
- 底部缩略图条默认**自动隐藏**：把鼠标移到窗口底部（缩略图条的位置或底栏上）
  就会淡入，移开 0.4 秒后淡出；悬停 0.5 秒显示文件名提示。**按住鼠标拖动图片时
  不会唤出**（拖着图经过底栏也不会突然弹出），松开后再移动即可。
  在“更多▾”里可切换为**常显**，设置页还可选择**关闭**。缩略图条可点击跳转、
  滚轮横向滚动、悬停显示文件名。
- **拖出文件**：按住 `Ctrl` 从图片上拖到资源管理器、聊天窗口或 Word，会以
  **复制**方式导出当前文件（源文件不会移动）；直接从缩略图条拖动某一项则导出
  那一项，不需要按 `Ctrl`。拖动中按 `Esc` 取消，松开左键完成。不按 `Ctrl`
  拖动图片仍是平移。
- 大文件/专业格式会**先显示预览、再变清晰**：RAW（如 CR2/NEF/ARW）先出相机内嵌
  的 JPEG 预览，PSD/PSB 和超过 32 MB 的图片先用缩略图缓存；右上角出现「预览」
  胶囊，全解完成后自动淡出。普通 JPEG/PNG 不会预览，因此不会“糊一下”。
  预览显示期间另存为/复制图像/设为壁纸会提示“原图仍在加载”，避免导出低清图。
  如果全解失败，预览会保留并叠加错误卡。
- 可选注册“打开方式”/右键菜单：

```powershell
zoreview.exe --register-shell        # 右键 3 个动词
zoreview.exe --register-assoc        # 加入“打开方式”
zoreview.exe --set-default-assoc     # 显式设为默认（会备份原默认值）
zoreview.exe --unregister-shell --unregister-assoc
```

## 支持的格式

| 类别 | 格式 |
| --- | --- |
| 常用 | JPEG、PNG、BMP、GIF、WebP、TIFF、ICO/CUR |
| 专业 | PSD/PSB（合并图）、相机 RAW（CR2/CR3/NEF/ARW/RAF/ORF/RW2/PEF/SRW/DNG） |
| 现代 | HEIC/HEIF、AVIF（依赖系统扩展） |
| 矢量 | SVG（Direct2D 光栅化） |
| 其他 | TGA、PCX、PNM（PBM/PGM/PPM）、XBM、XPM、WBMP、APNG |
| 高动态 | HDR（Radiance）、EXR（OpenEXR）、PFM（统一 Reinhard + gamma 2.2 色调映射） |
| 专业容器 | JP2/J2K/JPC（JPEG 2000）、JXR/WDP（JPEG XR，系统编解码器优先） |
| 动画 | GIF、APNG、WebP 动画（空格暂停/继续，底栏上方有帧控件）；MNG/JNG 只显示首帧 |

- EXIF 方向在解码阶段自动转正；非 sRGB 的 ICC profile 会转换到 sRGB。
- 多页 TIFF 只显示第一页；PSD/PSB 只显示文件内的合并图；MNG/JNG 只显示首帧。
- HDR/EXR/PFM 使用固定色调映射（Reinhard + gamma 2.2），与参考图一致；
  超过 200 MP 或 float 数据估算超过 1.5 GB 的文件会明确拒绝。

## 快捷键与鼠标

| 操作 | 快捷键 |
| --- | --- |
| 打开文件 | `Ctrl+O` |
| 另存为（PNG/JPEG/BMP/TIFF/WebP/GIF） | `Ctrl+S` |
| 复制图像 | `Ctrl+C` |
| 复制文件路径 | `Ctrl+Shift+C` |
| 重命名 | `F2` |
| 设为桌面壁纸 | `Ctrl+Shift+W` |
| 删除到回收站（需确认） | `Del` |
| 上一张 / 下一张 | `←` / `→` 或 `PgUp` / `PgDn` |
| 第一张 / 最后一张 | `Home` / `End` |
| 放大 / 缩小 | `+` / `-`（含小键盘） |
| 适应窗口 | `0` 或 `Ctrl+0` |
| 1:1 显示 | `1` 或 `Ctrl+1` |
| 信息面板 | `I` 或 `Alt+Enter` |
| 向左 / 向右旋转 90°（只改显示） | `Ctrl+L` / `Ctrl+R`，或底栏 `↺` / `↻` |
| 缩略图条：常显 ↔ 自动隐藏 | `Ctrl+T`（关闭状态只在设置页恢复） |
| 设置 | `Ctrl+,`，或点标题栏 `☰` 直接打开 |
| 深色/浅色主题 | `T` |
| 透明棋盘格 | `C` |
| 重新加载 | `F5` |
| 动画暂停/继续；静态图下一张 | `Space` |
| 动画上一帧 / 下一帧 | `,` / `.` |
| 全屏 / 退出全屏 | `F11` 或 `Enter` |
| 关闭浮层或退出全屏 | `Esc` |

鼠标：滚轮缩放（以光标为中心，`Ctrl+滚轮` 反向），左键拖拽平移，点击缩略图跳转；
有多个文件时，图像区左右两侧显示上一张/下一张圆钮；在缩略图条上滚动为横向滚动。
在设置 → 查看 里可以把滚轮改为“翻页”（此时 `Ctrl+滚轮` 仍然缩放）。

**全屏**：进入后右上角会先显示 **关闭** 与 **退出全屏** 两个按钮，3 秒后自动淡出；
把鼠标移到右上角会再次淡出显示，点它们可直接关窗或退出全屏。全屏下缩略图条
同样改为“移到窗口底部唤出”（不会一直占着画面），`Esc` 仍然退出全屏。

动画文件（GIF / APNG / WebP 动画）在底栏上方显示帧控件：`◀ 12 / 48 ▶ ⏸`。
左右箭头逐帧、中间按钮播放/暂停（`Space` 同效），`Esc` 不会关闭它；暂停后
`←/→` 仍然是切换文件，不会抢帧步进。有限循环播完后停在最后一帧并显示“已结束”，
再按播放会从第一帧重播；帧数被上限截断时会标注“已截断”。仅能显示首帧的文件
（例如系统缺少对应的动画解码能力）会显示“仅首帧”，不提供无效按钮。
最小化时自动暂停，恢复时只在之前正在播放的情况下继续；2 秒不动鼠标，控件淡到
35% 以让出画面，移动鼠标立即恢复。

文件夹到边界时的行为（本文件循环 / 下个文件夹 / 询问）也可以在设置 → 查看 里选择。
“下个文件夹”会按名称自然顺序找下一个含图片的子目录（空目录会跳过），
已经是最后一个时回到本文件夹第一张；选择“询问”时，到第一张/最后一张会弹出确认卡，
`Enter` 进入、`Esc` 留在本文件夹、`Space` 切换“记住我的选择”。

设置窗口（`Ctrl+,`）是自绘的非模态窗口，改动立即生效并保存：常规页有语言、主题、
棋盘格与透明度、缩略图条、鸟瞰图、记住窗口位置、单实例、始终置顶；查看页有
滚轮、缩放步长、最近邻放大（100% 以上生效，缩小仍用高质量插值）、保留旋转、全屏背景和边界行为；文件关联页可以按扩展名
注册/取消“打开方式”，或在二次确认后接管默认打开方式（可恢复）。
“恢复默认”会重置除语言、窗口位置和文件关联以外的全部设置，需要点击两次确认。

信息面板（`I` / `Alt+Enter` / 底栏 ⓘ）在右下角显示文件名、路径、大小、修改时间、
格式、尺寸、位深、帧数，以及拍摄信息（相机、镜头、拍摄时间、曝光、光圈、ISO、
焦距、曝光补偿、闪光、测光、白平衡、GPS）和 ICC 色彩配置。缺项显示“—”。
EXIF 在后台读取，打开面板不会卡住界面；翻到下一张时面板保持打开并自动刷新。
鼠标停在面板上滚轮只滚动面板；右键某一行复制该值，底部“复制全部”复制整份信息
（每行“标签: 值”，跳过缺项）。面板不抢焦点，`←`/`→` 仍然切图。没有 EXIF 的文件
（PNG/BMP/SVG/PSD 等）也能正常打开，只是拍摄组显示“—”，不会报错。

旋转只改变显示，不写原文件、不重新解码：切到下一张时默认保留旋转（设置
`keep_rotation`，默认开启），回到 0° 就是把剩下几圈转回去（`Ctrl+L`/`Ctrl+R` 或底栏
`↺`/`↻`，一个方向转四次即回原位）；另存为、复制图像和
设为壁纸都会按当前旋转后的画面输出。

另存为支持 PNG、JPEG、BMP、TIFF、WebP、GIF；保存框里只列出本机真能编码的容器
（例如没装 WebP 编码器的机器不会出现 WebP）。选 JPEG 或 WebP 时会弹出一个小卡片：
拖动“质量”滑条（或按 `←/→`，`Shift` 一次 10 格）即可看到“预计”大小，
`Enter` 保存、`Esc` 取消、`Tab` 在滑条和两个按钮之间切换。预估用的是和真正保存
完全相同的编码参数，误差通常在 1% 以内；超过 3200 万像素的大图不做预估（显示“—”）。
PNG/TIFF/WebP 保留透明，GIF 只保留 1-bit 透明。动画文件只保存当前显示的那一帧
（提示“已保存当前帧”）。保存是原子的：失败不会破坏原文件，也不会留下临时文件。
大于约 3200 万像素的图在后台编码，界面不会卡住。

右键菜单提供打开、另存为、复制、重命名、删除、设为桌面壁纸、在资源管理器中显示，以及语言切换。

窗口为自绘无边框样式：标题栏左侧显示"文件名 · 尺寸 · 文件大小"，
右侧是菜单、全屏、最小化、最大化/还原、关闭五个按钮（拖动标题栏移动窗口，
双击标题栏最大化/还原，边缘和四角可缩放，仍支持 Windows 贴靠与 `Alt+Space`）。
底部状态栏显示百分比与序号，并提供"适应 / 1:1"；窗口变窄时标题栏会自动隐藏
低优先级信息段，文件名始终保留（过长显示省略号）。

## 文件与数据位置

- 安装版：`%LOCALAPPDATA%\ZoreView\`
  - `settings.ini`：设置
  - `logs\zoreview.log`：日志（8 MB 轮转）
  - `crashes\`：崩溃转储（minidump）
  - `cache\`：磁盘缓存（可随时删除，会自动重建）
  - `wallpaper\wallpaper.bmp`：当前桌面壁纸文件，请勿当缓存清理
- 便携版：以上内容都在 `zoreview.exe` 所在目录。
- `zoreview.exe --print-paths` 可打印实际使用的路径。

## 命令行

```text
zoreview.exe [图片路径]
zoreview.exe --language zh|en          本次会话语言
zoreview.exe --set-language zh|en      保存界面语言
zoreview.exe --portable                本次以便携模式运行
zoreview.exe --register-shell | --unregister-shell
zoreview.exe --register-assoc | --set-default-assoc | --unregister-assoc
zoreview.exe --install [--machine] [--install-dir <目录>] [--no-shortcut] [--associate-default]
zoreview.exe --uninstall [--machine]
zoreview.exe --print-paths
```

## 常见问题

**HEIC/HEIF 打不开**
安装 Microsoft Store 的 “HEIF Image Extensions” 和 “HEVC Video Extensions”。
ZoreView 不自带 HEVC 解码器。

**AVIF 打不开**
安装 “AV1 Video Extension”。部分带独立 alpha 平面的 AVIF 只能显示颜色平面，
这是当前 Windows 解码器的限制。

**SVG 里的文字不显示**
内置 SVG 光栅化不渲染 `<text>`（以及部分滤镜/字体）。图形、路径、渐变正常；
需要完整文字渲染时请先用其他工具转成 PNG。

**APNG 只显示第一帧**
隔行（Adam7）APNG 暂不支持，会回退到首帧并写日志；普通 APNG 正常播放。

**WebP 动画只显示首帧**
WebP 动画依赖系统 WebP 解码器（Windows 11 自带或 “WebP Image Extensions”）。
解码器只能给出单帧时，帧控件会显示“仅首帧”，不会假装可以播放。

**RAW 打开慢/内存高**
30–45 MP RAW 单张解码约 1–3 秒、峰值可达数百 MB；这是解码器的工作集，
不是泄漏。缩略图约 1 秒。

**超大图（8K）内存**
单张 8K 峰值约 330 MB，连续翻页约 460 MB。超过 64 MB 的帧不进入缓存/预取。

**资源管理器没有缩略图**
确认已执行 `zoreview.exe --register-shell` 或安装器注册；Windows 11 的缩略图
宿主需要几秒刷新。仍不显示时，检查是否被杀软拦截 `ZoreViewThumb.dll`。
全机安装保持系统进程隔离，用户级安装使用进程内加载。

**界面语言/高 DPI**
右键菜单“语言”即时切换；设置会保存。界面按 per-monitor v2 DPI 缩放，
支持 100/125/150/200% 和多屏混合 DPI。

**日志和崩溃**
日志在 `logs\zoreview.log`，崩溃转储在 `crashes\`。反馈问题时附上版本号
（窗口标题/文件属性/`VERSION.txt`）和日志末尾。
